# Supply Chain Database Using SQL

// Project Overview //

This project demonstrates the design and implementation of a relational Supply Chain Database using SQL. The database simulates procurement and logistics operations by managing suppliers, projects, purchase requisitions, purchase orders, freight estimations, freight companies, and post-order expediting.

// Features //

Relational database design
Seven connected tables
Primary and Foreign Keys
Sample procurement data
SQL queries for data retrieval and analysis
ER Diagram
Documentation report

// Database Tables //

Suppliers
Projects
Purchase Requisitions
Purchase Orders
Freight Estimations
Freight Companies
Post Order Expediting
